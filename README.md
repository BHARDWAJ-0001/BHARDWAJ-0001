## `03 / FEATURED PROJECTS`

### ✳ AERIS — Personal AI Operating System

> A modular, voice-first Personal AI Operating System exploring AI reasoning, desktop automation, intelligent task execution, persistent memory, and system awareness.

AERIS explores how an AI system can move beyond conversation into a controlled execution layer that understands tasks, discovers tools, interacts with the environment, and performs actions with verification and recovery.

**Core capabilities**

- **AI reasoning & agent execution:** Modular tool-driven agents, dynamic action discovery, permission/confirmation workflows, controlled tool execution, audit logging, and undo capabilities.
- **Observe → Act → Verify → Recover:** Task orchestration, runtime-aware execution, and recovery workflows for failed or interrupted actions.
- **Desktop automation:** Browser control, file management, reminders, workflow execution, proactive task execution, and routine detection.
- **Persistent AI memory:** Local SQLite memory, full-text search, context-aware interactions, and long-term information management.
- **Computer vision & environment awareness:** Screen understanding, OCR, visual context processing, environmental awareness, and presence intelligence.
- **Voice-first interaction:** Voice commands, custom wake-word detection, and natural task execution.
- **PyQt6 command center:** System telemetry, task monitoring, voice interaction, AI visualization, and centralized control.
- **Security & reliability:** Encrypted secrets management, capability controls, rate limiting, isolated code execution, recovery workflows, and audit trails.
- **Testing:** The original project notes report 100+ automated tests covering AI functionality, automation, memory, security, and runtime behavior.

**Tech stack:** `Python` `Google Gemini Live API` `PyQt6` `SQLite` `Computer Vision` `OCR` `AI Agents` `Automation`
